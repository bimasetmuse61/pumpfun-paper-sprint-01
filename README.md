A hot-launch sniper that paper-trades pump.fun bonding curves: it buys only launches that are hot in their first 3 slots (at least 8 trades from at least 5 distinct buyers, creator not yet sold), takes profit fast (+10%), cuts losers (-12%), and never holds past 30 slots. Fully deterministic — no clock, no randomness, no network, no model calls. Dev grade: +0.264 SOL net PnL over 123 coins, max drawdown 3.5%, guardrails met.

## Run it

```sh
node main.ts
```
